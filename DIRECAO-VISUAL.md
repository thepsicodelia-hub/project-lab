# Project Lab — direção visual V1

Alvo: interface da Floow examinada nesta conversa, adaptada ao pedido de identidade azul. Construção direta solicitada pelo usuário, sem etapa de publicação ou repositório.

Consulta Refero: indisponível por NO_SUBSCRIPTION. Aplicado o fallback da própria skill: referência fornecida pelo usuário + guias locais de tipografia e detalhes de interface. Páginas oficiais Linear /features e Framer consultadas como contexto de ferramentas; não foram tratadas como referências visuais inspecionadas.

| Decisão | Fonte | Papel | Aplicação |
|---|---|---|---|
| Manter módulos e relações | Levantamento Floow | Estrutura de produto | Menu com 11 áreas e configurações |
| Grafite e superfícies discretas | Captura Floow + pedido de mudar visual | Base | #0c1018, #121923, bordas #232d3c |
| Azul | Pedido do usuário | Ação principal, seleção, progresso | #4a91ff; sem banho de brilho decorativo |
| Tipografia neutra | Refero typography.md | Leitura de trabalho | Segoe UI local, 9–32 px, números tabulares |
| Menu com texto persistente | Objetivo de navegar muitos módulos | Orientação | Sidebar 222 px; drawer no celular |
| Projeto no centro do painel | Fluxos observados na Floow | Hierarquia | Produção e lista à esquerda, metas/agenda à direita |
| Dados fictícios declarados | Etapa de protótipo visual | Honestidade | Identificação permanente da prévia |
| Ícones vetoriais, sem fotos | Conteúdo gerencial | Sinalização funcional | SVG locais de traço uniforme, sem assets remotos |
| Feedback curto | Skill emilkowalski-design fornecida pelo usuário | Interação | Estados de clique/foco, toasts; navegação instantânea |

Preservar: contraste, densidade útil, barra lateral, azul funcional, hierarquia de projeto/prazo. Rejeitar: fundo verde, glow generalizado, animação de entrada em toda navegação, fotos decorativas e números apresentados como dados reais.

Escopo: prévia navegável; interações locais para avaliar telas. Sem sincronização, login, automações de WhatsApp, servidor de dados ou publicação. Nome provisório Project Lab conforme pedido original e pasta PROJECT - LAB.
